VISUALISASI DATA SPASIO-TEMPORAL SEBARAN GEMPA BUMI INDONESIA MENGGUNAKAN MACHINE LEARNING UNTUK DETEKSI ANOMALI AKTIVITAS SEISMIK

ABSTRAK

Indonesia merupakan negara yang terletak pada Cincin Api Pasifik (Ring of Fire) dengan tingkat seismisitas tertinggi di dunia. Data katalog gempa bumi dari Badan Meteorologi Klimatologi dan Geofisika (BMKG) mencatat 92,415 kejadian gempa dari periode November 2008 hingga Januari 2023, mencakup rentang magnitude 1.0–7.9 dengan kedalaman 2–700 km. Penelitian ini mengembangkan aplikasi visualisasi interaktif berbasis web untuk eksplorasi pola spasio-temporal gempa bumi Indonesia serta mengintegrasikan teknik machine learning Isolation Forest untuk deteksi anomali aktivitas seismik. Aplikasi dibangun menggunakan HTML5, Leaflet.js untuk pemetaan interaktif, dan Chart.js untuk visualisasi timeline temporal. Komponen machine learning mengidentifikasi 4,366 observasi anomali berdasarkan kombinasi Isolation Forest dan Z-Score pada agregasi data grid bulanan. Hasil menunjukkan anomali terpusat pada periode dengan magnitude ekstrem (≥6.0) dan aktivitas gempa yang tidak biasa secara spasial. Aplikasi memungkinkan pengguna untuk mengeksplorasi pola gempa interaktif melalui slider temporal (2008–2023), layer management, dan visualisasi anomali real-time. Metodologi penelitian menggabungkan tahapan identifikasi data, pra-pemrosesan, perancangan visualisasi, dan integrasi machine learning secara koheren. Penelitian ini menunjukkan potensi visualisasi data spasio-temporal dan machine learning untuk analisis fenomena seismik kompleks dan dukungan pengambilan keputusan berbasis pola.

Kata kunci: visualisasi data spasio-temporal, machine learning, deteksi anomali, gempa bumi Indonesia, pemetaan interaktif

ABSTRACT

Indonesia is situated on the Pacific Ring of Fire with the highest seismicity level globally. The earthquake catalog from Indonesia's Meteorological, Climatological and Geophysical Agency (BMKG) records 92,415 seismic events from November 2008 to January 2023, spanning magnitudes 1.0–7.9 with depths of 2–700 km. This research develops an interactive web-based visualization application for exploring spatio-temporal patterns of Indonesian earthquakes and integrates Isolation Forest machine learning techniques for anomaly detection in seismic activity. The application is built using HTML5, Leaflet.js for interactive mapping, and Chart.js for temporal timeline visualization. The machine learning component identifies 4,366 anomalous observations based on a combination of Isolation Forest and Z-Score on monthly grid-based data aggregation. Results show anomalies concentrated on periods with extreme magnitude events (≥6.0) and spatially unusual earthquake activity. The application enables users to interactively explore earthquake patterns through a temporal slider (2008–2023), layer management, and real-time anomaly visualization. The research methodology combines data identification, preprocessing, visualization design, and machine learning integration coherently. This research demonstrates the potential of spatio-temporal data visualization and machine learning for analyzing complex seismic phenomena and supporting evidence-based decision-making.

Keywords: spatio-temporal data visualization, machine learning, anomaly detection, Indonesian earthquakes, interactive mapping

1. PENDAHULUAN

Indonesia merupakan negara kepulauan yang secara geografis terletak pada jalur Cincin Api Pasifik (Ring of Fire), sebuah zona tektonik dengan aktivitas vulkanik dan seismik tertinggi di dunia. Menurut Badan Geologi Kementerian ESDM, wilayah Indonesia mencakup pertemuan empat lempeng tektonik utama—Lempeng Eurasian, Lempeng Indo-Australia, Lempeng Pasifik, dan Lempeng Filipina—yang menyebabkan tingkat seismisitas rata-rata mencapai ratusan gempa per bulan. Aktivitas seismik ini menciptakan risiko signifikan bagi infrastruktur, penduduk, dan ekonomi nasional.

Data gempa bumi merupakan fenomena spasio-temporal kompleks yang memiliki dimensi ruang (koordinat geografis epicenter) dan dimensi waktu (tanggal dan waktu kejadian) secara simultan. Katalog gempa BMKG yang komprehensif mencakup 92,415 kejadian gempa dalam kurun 14 tahun (November 2008–Januari 2023), dengan variasi magnitude dari 1.0 hingga 7.9 dan kedalaman dari 2 hingga 700 kilometer. Dataset ini menyediakan peluang bagi peneliti untuk mengidentifikasi pola, tren, dan anomali dalam fenomena seismik yang tersembunyi dalam kumpulan data multidimensi.

Visualisasi data bukan sekadar alat presentasi pasif, melainkan medium analitik yang memungkinkan pengguna untuk melakukan eksplorasi intuitif terhadap struktur data, mengidentifikasi hubungan spasial, dan mengkomunikasikan temuan ilmiah kepada audiens beragam. Dalam konteks data seismik, visualisasi spasio-temporal interaktif memfasilitasi penemuan pola distribusi gempa geografis, identifikasi zona berisiko tinggi, dan pemahaman tren temporal dalam aktivitas seismos. Selain itu, integrasi teknik machine learning—seperti deteksi anomali—dapat mengungkap periode dan lokasi dengan aktivitas gempa yang secara statistik menyimpang dari pola umum, memperkaya interpretasi fenomena seismik.

Penelitian ini bertujuan untuk: (1) mengembangkan aplikasi visualisasi data spasio-temporal berbasis web yang interaktif dan responsif, (2) mengimplementasikan algoritma machine learning Isolation Forest untuk deteksi anomali aktivitas seismik, (3) mengintegrasikan hasil prediktif dan deskriptif ke dalam peta interaktif sebagai layer yang dapat diaktifkan pengguna, dan (4) mendokumentasikan metodologi secara sistematis dalam format artikel ilmiah yang memenuhi standar publikasi.

2. TINJAUAN PUSTAKA

2.1 Visualisasi Data Spasio-Temporal

Visualisasi spasio-temporal merupakan subdisiplin dalam infovisual yang menggabungkan representasi visual dari data yang memiliki dimensi ruang dan waktu secara bersamaan (Andrienko & Andrienko, 2006). Dalam dekade terakhir, kemajuan teknologi geospasial dan ketersediaan big data telah mendorong perkembangan pesat dalam teknik dan alat visualisasi. Pemetaan interaktif berbasis web, khususnya menggunakan pustaka seperti Leaflet.js dan Google Maps API, telah menjadi standar industri untuk eksplorasi data geografis (Bostock et al., 2011).

Menurut Fekete & Plaisant (2002), terdapat lima prinsip fundamental dalam perancangan visualisasi spasio-temporal yang efektif: (1) pemilihan representasi visual yang sesuai dengan jenis data, (2) integrasi dimensi temporal tanpa mengabaikan konteks spasial, (3) interaktivitas yang memungkinkan pengguna untuk mengontrol aspek temporal secara dinamis, (4) kejelasan legenda dan label informasi, dan (5) responsivitas performa untuk dataset besar.

Dalam konteks data gempa bumi, visualisasi spasio-temporal telah digunakan untuk berbagai keperluan: pemetaan distribusi epicenter, analisis clustering zona seismik, identifikasi rupture patterns pasca-gempa, dan monitorisasi aktivitas real-time. Studi oleh Melonakis & Poutachidis (2016) menunjukkan bahwa visualisasi interaktif yang menggabungkan peta dengan grafik temporal meningkatkan kemampuan analis dalam mengidentifikasi tren dan anomali hingga 40% dibandingkan analisis tabel data statis.

2.2 Machine Learning untuk Deteksi Anomali Seismik

Deteksi anomali (anomaly detection) adalah tugas unsupervised learning yang bertujuan mengidentifikasi observasi atau pola yang menyimpang signifikan dari distribusi normal data (Chandola et al., 2009). Dalam konteks data seismik, anomali dapat didefinisikan sebagai periode temporal atau lokasi spasial dengan karakteristik magnitude, kedalaman, atau frekuensi gempa yang tidak biasa berdasarkan konteks statistik dan domain.

Isolation Forest merupakan algoritma deteksi anomali berbasis pohon keputusan yang dikembangkan oleh Liu et al. (2008) dengan prinsip bahwa anomali merupakan observasi "langka" yang dapat diisolasi dengan lebih sedikit pemisahan (split) dibandingkan observasi normal. Keunggulan Isolation Forest mencakup: (1) efisiensi komputasi untuk dataset besar, (2) tidak memerlukan normalisasi fitur ekstensif, (3) tidak sensitif terhadap parameter, dan (4) dapat mendeteksi anomali lokal maupun global.

Pendekatan alternatif mencakup Local Outlier Factor (LOF), One-Class SVM, dan metode statistik klasik seperti Z-Score. Penelitian oleh Goldstein & Uchida (2016) menunjukkan bahwa kombinasi beberapa algoritma deteksi anomali (ensemble approach) menghasilkan performa yang lebih robust dibandingkan penggunaan algoritma tunggal. Dalam studi ini, kombinasi Isolation Forest dan Z-Score dipilih untuk validasi silang guna meningkatkan kredibilitas hasil deteksi anomali.

2.3 Data BMKG dan Karakteristik Seismik Indonesia

BMKG menyelenggarakan katalog gempa yang komprehensif dengan memanfaatkan jaringan seismometer nasional (seismic network) yang tersebar di seluruh nusantara. Menurut BMKG (2023), aktivitas seismik Indonesia dapat dikarakterisasi berdasarkan beberapa zona tektonik utama:

- Zona subduksi Sumatra: Megathrust earthquake dengan magnitude extreme (hingga 9.1 pada 2004)
- Zona Jawa dan Flores: Komplex subduction dengan intermediate-focus earthquake
- Zona Sulawesi: Multiple transform faults dengan strike-slip mechanism
- Zona Maluku-Banda: Back-arc spreading dengan aktivitas tinggi

Distribusi spasial gempa di Indonesia tidak random melainkan terkonsentrasi pada boundary lempeng dan fault zones tertentu, menciptakan pola geografis yang dapat diidentifikasi melalui visualisasi. Studi seismotektonik oleh Bock et al. (2003) memetakan laju subduksi dan slip distribution di berbagai zona, menyediakan konteks untuk interpretasi anomali aktivitas seismik.

3. METODOLOGI

3.1 Sumber dan Karakteristik Data

Data yang digunakan bersumber dari BMKG Open Data (katalog_gempa_indonesia.csv) dengan spesifikasi:
- **Total records**: 92,887 kejadian gempa (pre-processing)
- **Periode**: November 2008 – Januari 2023 (14 tahun, 160 bulan)
- **Variabel**: 13 kolom mencakup tanggal, waktu (origin time), latitude, longitude, kedalaman, magnitude, nama wilayah, dan focal mechanism parameters
- **Jangkauan spasial**: Latitude -11° hingga 7°, Longitude 95° hingga 141° (seluruh wilayah Indonesia)
- **Range magnitude**: 1.0 hingga 7.9 (Richter Scale)
- **Range kedalaman**: 2 hingga 700 kilometer

3.2 Tahap Pra-pemrosesan Data

Tahap pra-pemrosesan meliputi:

a) **Data Cleaning**: Verifikasi completeness, penanganan missing values (ditemukan 0 missing untuk variabel kritis), penghapusan duplikasi, dan deteksi outlier. Hasil: 92,415 records valid (99.9%)

b) **Format Normalization**: Konversi datetime strings ke format datetime Python, ekstraksi komponen temporal (tahun, bulan, hari, jam), dan standardisasi format koordinat geografis

c) **Spatial Validation**: Memverifikasi semua koordinat berada dalam bounds geografis Indonesia (-11° ≤ lat ≤ 7°, 95° ≤ lon ≤ 141°)

d) **Range Validation**: Filter magnitude 0–10 dan kedalaman 0–700 km sesuai konvensi seismologi

e) **Feature Engineering**: 
   - Magnitude categories: Minor (<3), Light (3-4), Moderate (4-5), Strong (5-6), Major (≥6)
   - Depth categories: Shallow (<70 km), Intermediate (70-300 km), Deep (>300 km)
   - Grid cell identifier: Kombinasi lat/lon rounded 0.1° untuk spatial clustering

3.3 Machine Learning: Deteksi Anomali Seismik

Tahap ML mencakup:

a) **Data Aggregation**: Agregasi earthquake data per grid cell (0.1° × 0.1°) dan per bulan, menghasilkan 70,234 observasi dengan fitur:
   - Event count (jumlah gempa per cell-bulan)
   - Maximum magnitude (mag terbesarnya)
   - Mean magnitude (rata-rata mag)
   - Mean depth (rata-rata kedalaman)

b) **Feature Normalization**: StandardScaler dari scikit-learn untuk normalisasi fitur ke mean=0, std=1

c) **Isolation Forest** (kontaminasi=5%, random_state=42, n_estimators=100):
   - Mengidentifikasi 3,512 anomali (5% dari data)
   - Output: anomaly_score (-1 hingga +1) dan anomaly_label (-1=anomali, +1=normal)

d) **Z-Score Validation** (threshold |Z| > 2):
   - Hitung Z-score untuk event_count dan mag_max
   - Mengidentifikasi 2,745 anomali berdasarkan statistik parametrik
   - Kombinasi (OR) dengan Isolation Forest: 4,366 anomali tervalidasi

e) **Result Interpretation**:
   - Top anomalies terpusat pada periode dengan magnitude ekstrem (6.0–7.9)
   - Anomali spasial berlokasi di zona subduksi aktif (Flores, Sulawesi)
   - Beberapa anomali konsisten dengan rupture patterns historical earthquakes

3.4 Desain Aplikasi Visualisasi

Aplikasi dibangun dengan arsitektur:

**Frontend**:
- HTML5 + CSS3 responsive grid layout

3. Map Interactions: Click popup untuk detail info, zoom/pan untuk exploration
4. Chart Responsiveness: Automatic update saat slider berubah
5. Export Button: Download data dalam format JSON

4. HASIL DAN PEMBAHASAN

4.1 Statistik Deskriptif Dataset

Setelah pra-pemrosesan, dataset final mencakup 92,415 kejadian gempa dengan distribusi:

**Magnitude**:
- Min: 1.0, Max: 7.9, Mean: 3.59, Median: 3.50
- Distribution:
  - Minor (< 3.0): 21,761 events (23.5%)
  - Light (3.0–3.9): 40,660 events (44.0%)
  - Moderate (4.0–4.9): 24,996 events (27.0%)
  - Strong (5.0–5.9): 4,596 events (5.0%)
  - Major (≥ 6.0): 402 events (0.4%)

**Kedalaman** (km):
- Min: 2, Max: 700, Mean: 48.8, Median: 39.0
- Distribution:
  - Shallow (< 70 km): 73,100 events (79.1%)—subduction zone intraslab
  - Intermediate (70–300 km): 17,751 events (19.2%)—intermediate-depth events
  - Deep (> 300 km): 1,564 events (1.7%)—deep slab earthquakes

**Distribusi Regional** (Top 5):
1. Minahassa Peninsula (Sulawesi): 9,428 events
2. Sulawesi (general): 7,893 events
3. Sumbawa Region: 7,312 events
4. Java: 6,797 events
5. Northern Sumatra: 5,832 events

Observasi: Konsentrasi gempa pada subduction zone interfaces—Sumatra, Jawa, Banda, Sulawesi—sesuai dengan teori tektonik lempeng dan historical seismicity patterns.

4.2 Hasil Machine Learning: Deteksi Anomali

Isolation Forest mengidentifikasi 3,512 anomali (5% dari 70,234 grid-month observations) dengan anomaly scores berkisar -0.8 hingga +1.0. Z-Score validation mengidentifikasi 2,745 anomali dengan threshold |Z| > 2.0. Kombinasi (OR logic) menghasilkan 4,366 observasi tervalidasi sebagai anomali.

**Top 10 Anomalies** (berdasarkan Isolation Forest score):

1. **Periode**: 2020-08, **Lokasi**: Flores Sea (-6.8°, 123.5°)
   - Events: 2, Magnitude Max: 6.7, Depth Mean: 663 km, IF Score: -0.769

2. **Periode**: 2017-01, **Lokasi**: Sulawesi (-4.4°, 122.6°)
   - Events: 2, Magnitude Max: 7.2, Depth Mean: 629 km, IF Score: -0.769

3. **Periode**: 2016-10, **Lokasi**: Java (-5.0°, 108.2°)
   - Events: 2, Magnitude Max: 6.3, Depth Mean: 614 km, IF Score: -0.767

Interpretasi: Anomali terkonsentrasi pada periode dengan magnitude ekstrem (> 6.0) dan kedalaman dalam (> 600 km), karakteristik deep slab earthquakes yang relatif jarang. Lokasi anomali konsisten dengan zona subduksi aktif—Flores, Sulawesi, Java—yang secara geologis merupakan rupture zones dengan recurrence interval lama.

4.4 Pembahasan Temuan

**Pola Spasio-Temporal**:
Visualisasi interaktif mengungkapkan bahwa distribusi gempa Indonesia tidak uniform melainkan terkonsentrasi pada boundary lempeng dan fault zones. Hotspot seismik terpusat pada:
- Subduction Sumatra (Northern-Central): Jutaan magnitude 6-7
- Java Trench: Mix shallow & intermediate-focus
- Banda-Flores zone: Deep slab seismicity
- Sulawesi: Transform fault + back-arc spreading

**Temporal Trend**:
Timeline menunjukkan variasi aktivitas bulanan dengan rata-rata 577.6 gempa/bulan. Peak aktivitas berkorelasi dengan eruption cycles (Sinabung 2013) dan major earthquake sequences (Lombok 2018, Palu 2018). Machine learning deteksi anomali efektif mengidentifikasi periode dengan magnitude ekstrem atau spatial clustering unusual.

**Machine Learning Efficacy**:
Isolation Forest + Z-Score combination menghasilkan 4,366 flagged anomalies, tapi hanya ~50 (1.1%) merupakan observasi dengan magnitude > 6.0 (truly extreme). Hal ini menunjukkan algoritma juga mendeteksi subtle spatial/temporal patterns (e.g., unusual clustering dalam region normally quiet), memberikan early warning potential untuk seismic hazard assessment.

**Aplikasi Praktis**:
Aplikasi ini memfasilitasi:
1. **Seismic hazard mapping**: Identifikasi zona high-frequency vs. extreme-magnitude
2. **Temporal analysis**: Monitor trend aktivitas dan deteksi regime shifts
3. **Anomaly-based early warning**: Flagging unusual activity untuk investigasi geophysical
4. **Educational visualization**: Komunikasi pattern gempa kepada stakeholder non-technical

5. KESIMPULAN

Penelitian ini berhasil mengembangkan aplikasi visualisasi data spasio-temporal interaktif untuk eksplorasi pola gempa bumi Indonesia (2008–2023) dengan integrasi machine learning untuk deteksi anomali aktivitas seismik. Aplikasi menggabungkan: (1) pemetaan interaktif berbasis Leaflet.js dengan 92,415 kejadian gempa, (2) kontrol temporal slider memungkinkan filter dinamis, (3) visualisasi timeline temporal, (4) layer management untuk eksplorasi multi-dimensi, dan (5) integrasi model ML Isolation Forest untuk identifikasi 4,366 anomali.

Hasil menunjukkan bahwa kombinasi teknik visualisasi interaktif dan machine learning mengungkapkan pola-pola penting dalam fenomena seismik kompleks: hotspot geografis konsisten dengan teori tektonik, anomali terkonsentrasi pada periode magnitude ekstrem, dan potensi aplikasi untuk seismic hazard assessment dan early warning systems.

Limitasi penelitian mencakup: (1) sampling 500 earthquakes untuk performa peta (potential representasi bias), (2) aggregation per grid 0.1° mungkin mask local-scale heterogeneity, (3) deteksi anomali berbasis unsupervised (validasi ground truth sulit), dan (4) kontrol temporal hanya year-level (fine-grained temporal exploration limited).

Rekomendasi penelitian lanjutan: (1) supervised learning untuk magnitude prediction, (2) hierarchical spatial aggregation untuk multi-scale analysis, (3) integration real-time seismic data feeds, (4) deployment sebagai operational early warning system, dan (5) expansion ke analisis multi-hazard (seismic + tsunami + landslide).

Kesimpulannya, visualisasi data spasio-temporal menyediakan powerful medium untuk eksplorasi fenomena geografis kompleks, dan integrasi machine learning memperkaya interpretasi ilmiah untuk dukungan keputusan berbasis data.
